# ❤️ Heart Disease Prediction Using Machine Learning

📌 Project Overview

This project uses Machine Learning to predict the possibility of heart disease based on patient health information.

🎯 Project Objectives

- Analyze heart disease dataset.
- Perform data preprocessing and visualization.
- Train a Machine Learning model.
- Predict heart disease using patient input.
- Build an interactive prediction application.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Jupyter Notebook

📂 Project Files

- "heart.ipynb" – Data Analysis and Model Training
- "heart.py" – Prediction Application
- "heart_model.pkl" – Trained Machine Learning Model
- "Heart-Disease-Prediction video.mp4" – Project Demo Video

⚙️ How to Run

1. Clone this repository.
2. Install the required libraries.
3. Run the Streamlit application.

pip install pandas numpy matplotlib seaborn scikit-learn streamlit

streamlit run heart.py
